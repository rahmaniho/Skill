    چطور داده واقعی بگیریم؟
    
        
      
          
    1. داکر را نصب کنید (Docker Desktop).
      2. 
          
    2. در ریشه مخزن: docker compose up -d — موتور روی localhost:8080.
      3. 
          
    3. این داشبورد را با python3 -m leadgen.server بالا بیاورید.
      4. 
          
    4. در تب «اسکراپ جدید» موتور را روی خودکار بگذارید و اجرا کنید.
      5. 
        
    
        
    اگر داکر ندارید
    
        
    برنامه با موتور دمو کامل کار می‌کند: همه مراحل (غنی‌سازی، امتیازدهی،
          کمپین، خروجی اکسل) با داده نمونه ولی واقع‌نما. برای همین تمام قابلیت‌ها را بدون اینترنت
          می‌توانید ببینید و تست کنید.
    
      
    
    
    

    
    
      
    
        
    دستورات سریع (ترمینال)
    
        
    # سلامت محیط
python3 -m leadgen.cli doctor

# فهرست اصناف و یافتن نزدیک‌ترین صنف
python3 -m leadgen.cli niches
python3 -m leadgen.cli niches "کارواش"

# اجرای کامل با خروجی اکسل
python3 -m leadgen.cli run "دندانپزشکی" --city "تهران" --profile web_design --socials

# پوشش کل شهر (۹ کاشی) با کلیدواژه فارسی
python3 -m leadgen.cli run "رستوران" --city "تهران" --lang fa --grid 3 --depth 5

# امتیازدهی به فهرست موجود خودتان
python3 -m leadgen.cli score-file my-leads.csv --profile marketing

# تولید متن کمپین واتس‌اپ
python3 -m leadgen.cli campaign <run-id> --channel whatsapp --out messages.csv
    
      
    
      
    
        
    رعایت قانون و اخلاق
    
        
      
          
    • ایمیل و تلفن داده شخصی هستند: مبنای قانونی، هویت فرستنده و گزینه «لغو دریافت» را در هر پیام نگه دارید (GDPR / CCPA / CAN-SPAM).
      • 
          
    • اسکراپ گوگل‌مپ با شرایط استفاده گوگل هم‌خوانی ندارد: حجم را متعادل نگه دارید، خروجی را «لیدِ نیازمند تأیید» بدانید و داده خام را نفروشید.
      • 
          
    • از این ابزار برای نظارت بر افراد، اسپم یا آزار استفاده نکنید.
      • 
          
    • موتور کیت هیچ احراز هویتی ندارد؛ روی 127.0.0.1 بماند. اگر این داشبورد را منتشر می‌کنید، پشت پراکسی احراز هویت بگذارید.
      • 
          
    • خروجی‌ها در data/ ذخیره می‌شوند و در .gitignore هستند — هرگز commit نشوند.
