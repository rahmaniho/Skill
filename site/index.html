LeadGen Studio روی اسکیل google-maps-scraper ساخته شده: کلیدواژه‌های فارسی/انگلیسی می‌سازد، job را داخل داکر اجرا می‌کند، CSV خام ۳۴ ستونی را پاک‌سازی و غنی می‌کند (ایمیل، اینستاگرام/فیسبوک/لینکدین، مختصات lat/lon و پلاس‌کد)، به هر کسب‌وکار امتیاز «داغ/گرم/سرد» می‌دهد، متن کمپین آماده ارسال می‌نویسد و خروجی Excel/CSV/JSON فارسی تحویل می‌دهد — با داشبورد وب و CLI.

رابط ساده: یک جمله → خروجی

همان موتور و همان مغز، اما بدون هیچ تنظیم فنی: می‌نویسید «دندانپزشکی در تهران» یا «همه مشاغل در مشهد» و برنامه صنف، شهر، زبان، کلیدواژه‌ها، عمق جست‌وجو و حجم کار را خودش تشخیص می‌دهد؛ پیش از اجرا هم زمان تقریبی و خلاصهٔ تصمیمش را نشان می‌دهد.

  • همین‌جا امتحان کنید — نسخهٔ نمایشی، بدون سرور
  • پیشنهاد خودکار صنف و شهر + انتخاب «هدف» و «اندازه» با یک کلیک
  • تنظیمات پیشرفته پشت یک بخش بازشو: تا لازم نشود، دیده نمی‌شوند
🗺️

نسخهٔ جمع‌وجور: استان ← شهر ← منطقه ← خیابان

یک صفحهٔ کوچک با یک جعبهٔ جست‌وجو و چهار انتخابگر آبشاری. محدوده را تا سطح یک خیابان کوچک کنید (شعاع ۹۰۰ متر)، «همهٔ کسب‌وکارها» را بزنید یا یک صنف خاص را انتخاب کنید؛ بعد با فیلترهای تماس، امتیاز، ستاره و شعاع، همان داده‌ها را غربال کنید.

  • همین‌جا امتحان کنید — نسخهٔ نمایشی با دادهٔ نمونه
  • ۳۱ استان، ۱۶۳ شهر (۱۱۷ شهر ایرانی)، ۲۵۰+ منطقه و ۱۳۰+ خیابان با مختصات آماده — بدون اینترنت
  • «جست‌وجوی قوی»: چند کلمه‌ای، روی همهٔ اجراهای قبلی، با فیلتر شعاع حول منطقهٔ انتخابی
  • نام منطقه/خیابان را داخل جمله هم می‌فهمد: «کافه در چیتگر تهران»، «cafes in Saadat Abad»
🧭

جست‌وجوی تمامی مشاغل

یک جاروی چندصنفی روی کل شهر: ۹۱ صنف در ۱۳ گروه، نوبت‌دهی گردشی تا نتیجه تک‌صنفی نشود، یکتاسازی بین صنف‌ها و تگ «صنف منبع» روی هر ردیف.

  • --all-niches یا کلید «تمامی مشاغل» در داشبورد
  • فیلتر گروه: «سلامت و پزشکی، غذا و نوشیدنی»
  • jobهای متوالی + هشدار (نه توقف) برای اجراهای بزرگ
📍

لوکیشن دقیق

مختصات lat/lon هر کسب‌وکار، پلاس‌کد، رشتهٔ «لوکیشن دقیق» و لینک مستقیم نقشه — هم در جدول، هم در خروجی، هم روی نقشه پراکندگی.

  • لینک مکان گوگل یا maps/search/?api=1&query=lat,lon
  • پیش‌تنظیم ستون location برای کار میدانی
  • کاشی‌بندی شبکه (grid) برای پوشش کل شهر
✉️

غنی‌سازی ایمیل و شبکه اجتماعی

واکشی سایت هر کسب‌وکار (موازی، با کش)، استخراج mailto: و ایمیل‌های متنی، پاک‌سازی دامنه‌های junk، و پیدا کردن اینستاگرام/فیسبوک/لینکدین از صفحه و صفحات تماس/درباره ما.

  • پوشش معمول ۴۰–۷۰٪ بدون هیچ هزینه توکن
  • تشخیص سیگنال: سازنده سایت آماده، بدون آنالیتیکس، رزرو آنلاین
  • نرمال‌سازی تلفن ایران و تفکیک موبایل/ثابت
🎯

امتیازدهی هوشمند لید

پنج پروفایل فروش (طراحی سایت، بازاریابی، تأمین B2B، استخدام، عمومی) با پنج عامل وزنی: شکاف دیجیتال، دسترس‌پذیری، اعتبار، فعالیت و تناسب با صنف.

  • بخش‌بندی داغ 🔥 / گرم 🌤 / سرد ❄️ با آستانهٔ هر پروفایل
  • شناسایی ۹ شکاف دیجیتال و انتخاب «زاویه فروش»
  • breakdown امتیاز برای هر لید ذخیره می‌شود
💬

کمپین آماده ارسال

برای هر لید: دنباله ۳ لمسی ایمیل (روز ۰/۳/۸)، واتس‌اپ، پیامک ≤۲۸۰ نویسه، دایرکت ۲ قدمی اینستاگرام و سناریوی ۶ مرحله‌ای تماس تلفنی — شخصی‌سازی‌شده با نام کسب‌وکار، صنف، شهر و شکاف شناسایی‌شده.

  • لینک mailto: و wa.me یک‌کلیکی
  • امضا و «لغو دریافت» در هر متن (CAN-SPAM)
  • نسخه انگلیسی برای بازارهای خارج از ایران
📊

خروجی و داشبورد

Excel چندبرگی (لیدها، داغ‌ها، خلاصه، شکاف‌ها، قیف، بینش‌ها، کمپین) با RTL و فیلتر خودکار — نوشته‌شده بدون هیچ کتابخانه‌ای — به‌همراه CSV با BOM و JSON.

  • ۴ پیش‌تنظیم ستون: lead / contact / location / all
  • داشبورد وب: اجرا، کاوش لید، آنالیتیکس، کمپین، import
  • SQLite محلی برای پیگیری وضعیت هر لید (CRM سبک)

موتور واقعی یا دمو

با داکر، همان قرارداد اسکیل کیت: POST /api/v1/jobs، نظرسنجی Status، دانلود CSV. بدون داکر، موتور شبیه‌ساز داخلی همان ۳۴ ستون را با داده قطعی می‌سازد تا کل پایپ‌لاین قابل تست و نمایش باشد.

  • API فقط روی 127.0.0.1 — بدون احراز هویت، بدون شبکه عمومی
  • پشتیبانی از پروکسی socks5/http/https برای اجرای سنگین
  • ./run.sh doctor سلامت محیط را گزارش می‌دهد

در سه دستور روی دستگاه خودتان

نیاز به پایتون ۳.۱۱+ و داکر. هیچ پکیج پایپ لازم نیست (فقط کتابخانه استاندارد).

۱) موتور اسکراپ (داکر)

# مخزن را بگیرید و موتور را بالا بیاورید
git clone https://github.com/rahmaniho/Skill.git && cd Skill
cp .env.example .env
docker compose up -d          # gosom/google-maps-scraper روی 127.0.0.1:8080
curl -s http://localhost:8080/api/v1/jobs   # بررسی سلامت موتور

پورت فقط به 127.0.0.1 بایند می‌شود؛ API موتور احراز هویت ندارد و نباید عمومی شود.

۲) داشبورد وب

./run.sh serve        # http://localhost:8000
# یا مستقیم:
python3 -m leadgen.server --host 0.0.0.0 --port 8000

./run.sh doctor      # سلامت محیط: داکر، اصناف، شهرها
./run.sh demo        # اجرای نمونه بدون داکر (موتور دمو)
./run.sh test        # ۱۲۸ تست واحد

اگر داکر در دسترس نباشد، برنامه به‌صورت خودکار به موتور دمو می‌رود تا پایپ‌لاین کامل قابل آزمایش باشد.

CLI، API و پیش‌تنظیم ستون‌ها

هر کاری که در داشبورد ممکن است، با خط فرمان و HTTP هم ممکن است.

🏃 اجرای تک‌صنفی

python3 -m leadgen.cli run "دندانپزشکی" --city "تهران" \
  --lang fa --profile web_design --socials \
  --export xlsx --cols contact

# پوشش کل شهر با کاشی ۳×۳
python3 -m leadgen.cli run "رستوران" --city "دبی" --grid 3 --lang fa

🧭 جاروی تمامی مشاغل

python3 -m leadgen.cli run --all-niches --city "تهران" \
  --max-niches 12 --keywords-per-niche 2 --keywords-per-job 8 \
  --cols contact --limit 400

# فقط گروه‌های مشخص
python3 -m leadgen.cli run --all-niches --city "مشهد" \
  --groups "سلامت و پزشکی,غذا و نوشیدنی" --engine demo

🧰 دستورهای دیگر

python3 -m leadgen.cli niches            # ۹۱ صنف در ۱۳ گروه

python3 -m leadgen.cli profiles          # پروفایل‌های امتیازدهی

python3 -m leadgen.cli campaign <run_id> --channel whatsapp

مسئولیت و مقررات

قبل از استفاده بخوانید

این ابزار برای ساخت فهرست leads است، نه برای انبوه‌سازی داده شخصی یا فروش داده خام.

⚖️ شرایط استفاده گوگل

اسکراپ گوگل‌مپ با شرایط استفادهٔ گوگل سازگار نیست. خروجی را «فهرست اولیه» بدانید و پیش از تماس، اطلاعات را از منابع رسمی راستی‌آزمایی کنید. داده خام را نفروشید.

🔒 حریم شخصی و قانون
